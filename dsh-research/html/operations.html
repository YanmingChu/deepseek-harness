⚡ 日常 3 步同步官方最新代码 高频推荐
1

拉取 DeepSeek 官方主仓的最新提交

从 upstream 获取官方最新合并的 PR、功能和 Bug 修复：

git fetch upstream
2

将官方 master 分支合并到你的研究分支

合并最新官方主干，由于研究笔记在 dsh-research/，可以无缝平滑合并：

git merge upstream/master
3

推送到你的云端个人仓库

将合并后的最新代码同步到你的个人 GitHub Fork 仓库中：

git push origin my-branch
💻 在其他新电脑上同步研究 多端开发

换到新电脑时，克隆个人仓库并绑定上游源：

# 1. 克隆个人 Fork 仓库
git clone git@github.com:YanmingChu/deepseek-harness.git
cd deepseek-harness

# 2. 切换到专属研究分支
git checkout my-branch

# 3. 关联官方上游仓库
git remote add upstream https://github.com/deepseek-ai/deepseek-harness

# 4. 安装依赖并完成首轮全量构建
pnpm install
pnpm run build
🔑 SSH 代理配置与连通性验证 免密稳定

已配置 SOCKS5 代理隧道（端口 7890），可随时验证连通性：

ssh -T git@github.com
✅ 正常返回：Hi YanmingChu! You've successfully authenticated, but GitHub does not provide shell access.

🔍 常见问题与快速排错
问题现象 可能原因 排查与解决方案
Connection was reset Git 未走代理或代理端口未监听 检查代理软件是否开启 7890 端口，并运行 ssh -T git@github.com 测试。
typecheck 找不到模块声明 工作区尚未完成 TypeScript 构建 执行 pnpm run build 生成 lib/ 目录声明文件。
Web 控制台调用模型无响应 根目录未提供有效 DEEPSEEK_API_KEY 检查 .env 文件中的 Key 是否有效，或检查代理是否允许连接 api.deepseek.com。
