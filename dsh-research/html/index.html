DeepSeek Harness (`dsh`)
架构全景与二次开发指南

面向大语言模型（LLM）的开源 Agent 运行底座与执行调度框架。系统采用“一切皆插件”的纯解耦设计，为智能体提供安全隔离、确定性事件溯源与全平台操作调度能力。

🧩

1. 核心设计三原则

一切皆插件 (Plugin-First)

基于 Cordis 微内核，系统内不存在特权内核。从 LLM 适配器、文件读写、持久化终端到 Agent Loop 调度循环本身全部以插件挂载，可热插拔与配置覆写。

模型可见即已记录 (Logged)

采用 事件溯源（Event Sourcing） 架构。进入模型请求的所有输入、思维链、工具调用及结果均被严格持久化为 SessionEvent，支持 100% 状态重放与分支派生。

能力解耦 (Capability Seams)

严格三层解耦：接口定义 (Service Definition) $\to$ 服务实现 (Provider) $\to$ 消费端 (Consumer)。切换底层环境（如切到 Docker/沙箱）无需重写工具或重训模型。

⚖️

2. 本地 Harness 与云端大模型的分工全景

💻 本地 Harness (身体与双手)

执行与感知中枢
🖥️
交互与界面：提供 Web 控制台、React 对话流、代码 Diff 预览与 CLI 命令。
📂
工作区管理：本地工程代码扫描、AST 分析、文件读写与修改落地。
⚡
命令与代码执行：在你的电脑上真实启动 PowerShell / Bash 进程执行测试与构建。
🛡️
安全沙箱与审批：底层进程沙箱防护（Landlock/Bubblewrap），拦截危险指令。
💾
数据持久化：会话历史、断点恢复记录保存在本地硬盘（~/.dsh）。

☁️ DeepSeek 云端后台 (大脑)

思考与决策集群
🧠
推理计算集群：运行 DeepSeek-V3 / DeepSeek-R1 大模型。
💡
意图与上下文理解：理解用户下达的 Prompt 需求与多轮对话历史。
🔗
长链思考 (CoT)：进行深度推理，生成决策步骤与思维链。
🎯
工具调用决策：决定调用哪个 Tool（如 execute_shell）并生成入参 JSON。
🔒
无硬盘访问权：云端无法直接访问你的硬盘，也不提供代码执行环境。
🔒 数据隐私与完全离线运行能力

1. 代码零静默上传：云端无文件系统权限，仅随 Prompt 发送显式读取的代码片段。

2. 命令 100% 本地执行：模型仅返回 JSON 指令，本地 Harness 在你的电脑上真实拉起进程。

3. 支持完全离线：利用 packages/llm 适配层，可一键切换为本地 Ollama / vLLM，实现 0 数据上云的完全私密运行。

4. 智能体核心调度循环 (Agent Loop Lifecycle)

Agent 的单次交互为一个 轮次（Turn），一个轮次内部由一个或多个 步骤（Step） 组成。

    participant LLM as 模型服务 (ctx.llm)
    participant Tools as 工具流水线 (ctx.tools)
    participant Log as 会话日志 (Session Log)

    Note over Loop: turn/start (开启轮次)
    User->>Loop: 领取输入消息 (Inbox Claim)
    Loop->>Prompt: 组装 Prompt 片段 + Tool Schemas
    Loop->>Loop: 触发 waterfall: agent/pre-step (可改写/拦截)

        Note over Loop: step/start (进入单步执行)
        Loop->>Log: 追加 user/message 持久化事件
        Loop->>Log: deriveMessages() 派生历史上下文
        Loop->>LLM: 发起请求 (agent/request -> llm/stream)
        LLM-->>Loop: 流式返回 assistant/chunk* -> assistant/message

        opt 存在工具调用 (Tool Calls)
            Loop->>Tools: tools/pre-execute (权限校验/审批)
            Tools->>Tools: tools/execute (执行底层文件/命令)
            Tools->>Tools: tools/post-execute (结果过滤)
            Tools->>Log: 追加 tool/result* 持久化事件
        end
        Note over Loop: step/end (单步结束)

    Loop->>Loop: 触发 serial: agent/turn-stopping
    Note over Loop: turn/end (轮次关闭)

6. 六大专题研究与二次开发路线

专题 ①：Agent Loop 核心调度与上下文控制

🎯 研究目标：掌握 Agent 如何在多步骤中保持记忆、处理上下文溢出以及动态拦截 Prompt。

  • 📂 核心源码： packages/core/agent-loop、 packages/core/system-prompt、 packages/core/session
  • 🔍 核心机制：
    1. agent/pre-step 瀑布流拦截器：如何在模型请求前动态改写或拒绝消息。
    2. deriveMessages()：如何从纯追加的 SessionEvent 日志高效投影出模型历史。
    3. 长对话压缩（packages/compaction）：当 Token 逼近上限时自动触发历史压缩。
专题 ②：扩展自定义 Tool 与 Skill 插件

🎯 研究目标：为 Agent 注入操作本地软件、自定义数据库、私有 API 的专属能力。

  • 📂 核心源码： packages/core/tools、 packages/skill、 docs/cookbook/adding-a-tool.zh.md
  • 🔍 核心机制：
    1. 使用 ctx.tools.register() 声明 Schema 与执行函数。
    2. 执行流水线把关：tools/pre-execute $\to$ tools/execute $\to$ tools/post-execute。
    3. 声明前端渲染意图（generic / terminal / diff）。
专题 ③：多模型 LLM 适配器接入 (OpenAI / Claude / 本地 Ollama)

🎯 研究目标：摆脱单一模型依赖，接入第三方云端 API 或本地部署模型。

  • 📂 核心源码： packages/llm/、 docs/cookbook/adding-an-llm-adapter.zh.md
  • 🔍 核心机制：
    1. 在 ctx.llm 注册统一适配器接口。
    2. 将各模型流式输出转换为 assistant/chunk、tool/call 等标准事件。
    3. 支持本地部署框架（vLLM / Ollama / SGLang）的私密流式推理。
专题 ④：Web UI 定制与跨平台桌面客户端 (Desktop App)

🎯 研究目标：深度定制界面交互，或将 Harness 打包为独立的 .exe / .dmg 桌面软件。

  • 📂 核心源码： apps/web、 packages/client/
  • 🔍 核心机制：
    1. 前端采用 React 18 + Vite 架构，模块间高度解耦（侧边栏、对话气泡、主题配色）。
    2. 桌面化方案：引入 Tauri 或 Electron，将前端静态产物与 Node 后端打包封装为本地安装程序。
专题 ⑤：多 Agent 协作 (Subagents / Teams) 与工作流编排

🎯 研究目标：实现主智能体将复杂任务拆解委派给子智能体，或组建专家团队协同作业。

  • 📂 核心源码： packages/subagent、 packages/plan、 packages/workflow
  • 🔍 核心机制：
    1. Subagent 任务委派：主 Agent 发起子会话并等待结果结算。
    2. Agent Teams：持久化 Roster 成员花名册、Task Board 任务看板与 Mailbox 邮箱通信。
    3. 基于 Worker 线程的长流程状态编排。
专题 ⑥：底层安全沙箱隔离与权限审批

🎯 研究目标：保障代码运行安全，防止 Agent 产生误删或破坏性行为。

  • 📂 核心源码： packages/sandbox、 packages/interaction
  • 🔍 关键机制：
    1. 操作系统底层防护：Linux (Landlock / Bubblewrap)、macOS (Seatbelt)。
    2. 敏感操作（高危 Shell 命令、破坏性写入）弹出用户交互式确认窗口。
